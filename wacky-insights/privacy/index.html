Privacy Policy

Last updated: 7 September 2026

Overview

Wacky Insights Shorts Automation is a personal application used by the owner of the Wacky Insights YouTube channel. It is not a public service and is not intended for use by third parties.

Information accessed

The application uses Google OAuth and the YouTube Data API to access only the permissions granted by the channel owner. This access is used to upload and manage videos on the owner's YouTube account.

How information is used

Google and YouTube account authorization data is used solely to authenticate the owner and perform requested YouTube API operations. The application does not sell personal information, build advertising profiles, or share Google user data with third parties for unrelated purposes.

Storage and security

OAuth credentials and tokens used by the automation are stored in private, access-controlled configuration such as repository secrets. They are not intentionally exposed in public source code or public web pages.

Data retention and deletion

The application does not maintain a public user database. Authorization can be revoked at any time from the Google Account permissions page. Stored credentials can also be removed from the application's private configuration by the owner.

Google API Services User Data Policy

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements, where applicable.

Contact

Questions about this policy may be directed to the developer contact email shown on the application's Google OAuth consent screen.
