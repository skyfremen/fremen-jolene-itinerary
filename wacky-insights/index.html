WACKY INSIGHTS

Wacky Insights Shorts Automation

A personal automation application used by the owner of the Wacky Insights YouTube channel to prepare and upload original short-form videos.

What this application does

The application creates a finished video outside of YouTube and uses the YouTube Data API to upload that video to the channel owner's own YouTube account. It is not offered as a public service and does not provide third-party users with access to the channel or YouTube account.

Google and YouTube API access

The application uses Google OAuth to authorize the channel owner and uses the YouTube Data API only for functionality required to upload and manage videos on that owner's channel.
